# Third-party content

`icon-themes/atom/` contains the icons and file associations of **Atom Material Icons**
(https://github.com/AtomMaterialUI/a-file-icon-vscode), MIT License, Copyright (c) 2015-2024 Elior "Mallowigi"
Boukhobza and Philipp "PKief" Kief. The full license is in `icon-themes/atom/LICENSE.md`.
The Chernobyl icon themes add the NuclearLang icons and recolor the generic folder.

The code metrics (`lsp/src/metrics.rs` of nuclear-lsp, the "Code Metrics" settings and the details list) are a
port of **CodeMetrics** (https://github.com/kisstkondoros/codemetrics) and its library **tsmetrics-core**: the
same settings, default costs and messages. MIT License, Copyright (c) Tamás Kiss.
